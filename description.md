Проблематика:\
Сервис мониторинга API, должен решать проблемы отслеживания работы API, который
добавляют пользователи сайтов, чтобы отслеживать то, работает ли их API или нет. Также в случае падения API пользователю, который добавил его для отслеживания будет приходить сообщение о проблеме с его API
в виде сообщения в ТГ или в другой удобной форме (EMAIL и тд.)

Пользователи:\
Пользователями данного сервиса будут является владельцы сайтов, который заинтересованы в том, чтобы отслеживать работоспособность своего API, в случае возникновения проблем получая оповещения о отказе API

Основной сценарий пользователя:\
Существует пользователь\
Добавляет endpoint\
Сервис отправляет запрос на endpoint каждые 5 минут\
Результат сохраняется\
Пользователь получает историю и рассчитанный uptime

В MVP будет входить следующее:
1. Авторизация/регистрация/индетификация пользователя
2. Возможность добавления API в список пользователя который его добавил
3. Возможность получения информации об uptime API
4. Проверка работоспособности API, который добавил пользователь
5. Отправление сообщений пользователям в случае падения API

В MVP не будет входить следующее:
1. пока не придумал, дополнительные фичи

Критерий готовности:\
Минимальный UI в котором будет отображена возможность регистрации/авторизации пользователя, возможность реализации личного кабинета, в котором можно добавить endpoint сайта


Параметр по которому система понимает что endpoint не работает:
1. Таймаут
2. Ошибки 400-500

Параметр по которому система понимает что endpoint работает:
1. Код 200 (с возможным телом JSON)
